# Meme 核心模块讲解与面试指南

这里集中保存 Meme 核心模块的工程讲解。每篇文档只提炼一个主亮点，帮助维护者和面试者用一致的结构说明：解决了什么问题、系统如何工作、为什么这样设计、当前边界在哪里。

模块文档不是新的产品范围决策。功能范围以 ADR 为准，当前运行事实以代码和 [CURRENT-SYSTEM.md](../architecture/CURRENT-SYSTEM.md) 为准。

## 统一写作结构

后续模块按以下结构编写，避免重复创建零散说明文档：

1. 一句话亮点与简历表述。
2. 一分钟完整讲解。
3. 业务问题与系统边界。
4. 核心架构和端到端链路。
5. 关键设计与工程取舍。
6. 当前限制和后续改进。
7. 高频面试问题与参考回答。
8. 演示路径与代码证据。
