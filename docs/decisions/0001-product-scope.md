# ADR-0001：聚焦知识库、长期记忆与可解释评测

- 状态：Accepted
- 日期：2026-08-18
- 决策者：项目所有者
- 关联：Issue #1、PR #2

## 背景

Meme 的初始代码基线包含知识库、记忆、Agent、深度研究、多 Agent 群聊、定时任务、通知、情绪、音乐、分享和评测等大量功能。全部保留会增加启动、维护和面试讲解成本，也会模糊项目的个人贡献主线。

## 决策

Meme 的核心定位确定为：

> 一个可解释、可评测的个人 AI 知识库与长期记忆助手。

### 核心保留

- 账号、用户隔离和模型配置。
- 知识库、文档入库、混合检索和引用。
- 单人流式对话。
- 个人记忆、图谱、主动召回和跨会话上下文。
- Trace、Token、成本和离线评测。

### 保留但首版隐藏

- 定时 Agent 任务：保留为高级能力，不出现在首版主导航。
- 深度研究与 Verifier Loop：作为后续高级案例。
- 复杂标签管理：保留底层能力，暂不作为核心体验。
- Word 报告导出：随研究模块后置。

### 重设计后保留

- 首页、Agent 设置、Skills、MCP、图片知识、全局搜索和图谱解释。
- 图片首版保留知识入库与聊天附件，完整图库管理后置。

### 确认删除

- 情绪分析。
- 音乐库与情绪推荐。
- 多 Agent 群聊。
- 多渠道通知。
- 收藏。
- 对话公开分享。
- 报告公开分享。

## 定时任务与通知的边界

定时任务本身能展示 Celery Beat、调度、任务状态机和 Agent 自动化，具有工程与面试价值，因此保留。通知只是结果交付渠道，不应成为任务执行的硬依赖。

后续重构要求：

- 定时任务在没有通知配置时仍能完整运行。
- 结果和错误可在站内任务历史中查看。
- 删除通知渠道前，先移除任务对通知服务的强依赖。
- 首版导航隐藏定时任务，核心流程稳定后再决定展示位置。

## 结果与约束

- 产品首次演示聚焦“导入知识 → 带引用问答 → 写入记忆 → 跨会话召回 → 查看 Trace/评测”。
- 所有确认删除项分别建立 Issue 和 PR，不在一个提交中批量删除。
- 先移除入口和调用，再处理 API、任务与数据表。
- 已发布 Alembic 迁移不得修改；数据库清理通过新迁移完成。
- 本 ADR 确认产品范围，不代表已解决 upstream 代码授权；仓库继续保持私有，公开前另行确认授权。
